# Игра Memory Game

🔗 **Ссылка на игру:** [astvenfeltig.github.io/memory-game](https://astvenfeltig.github.io/memory-game/)

## Описание

Игра начинается автоматически при загрузке страницы. Перед вами 8 пар карт. Цель игры — найти все совпадающие пары за наименьшее количество ходов.

## Механика игры

- При нажатии на карту она переворачивается.
- При нажатии на вторую карту она также переворачивается.
- Если карты совпали — они остаются открытыми.
- Если карты не совпали — обе переворачиваются обратно.
- Каждый переворот карты считается за один ход.

## Интерфейс

На странице расположены:

- кнопка **«Начало игры»**;
- список **рекордов** из 10 лучших результатов;
- **игровое поле**;
- ссылка на **разработчика**.

## Начало новой игры

Новую игру можно начать двумя способами:

1. Нажать кнопку **«Новая игра»** в шапке сайта.
2. Нажать кнопку **«Новая игра»** в модальном окне после завершения игры.

## Модальное окно победы

После победы появляется модальное окно, в котором:

- обязательно нужно ввести **имя игрока**;
- доступны две кнопки: **«Новая игра»** и **«Закрыть окно»**.
